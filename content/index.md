# См. актуальную базу знаний на [sp404.ru](https://sp404.ru/)

Это репо — пробный тест, проверить, как работает публикация из Obsidian в GitHub Pages.
Актуальная и пополняемая база знаний по линейке сэмплеров Roland SP-404 – в публичном репо [sp404community/sp404community.github.io](https://github.com/sp404community/sp404community.github.io) 

Страницы публикуются по адресу [sp404community.github.io](https://sp404community.github.io/) к которым настроен домен [sp404.ru](https://sp404.ru/)

> [!warning] Всё остальное здесь — только для проверки.


-----

Русскоязычное сообщество пользователей легендарной линейки сэмплеров Roland.

#### Приветствуем дополнения и исправления
Самое простой способ: написать в [телеграм чате](https://t.me/sp404community) сообщества, там обитают участники, которые обновляют эту базу знаний.

> [!info]- Для разработчиков
> Если Вы есть на GitHub, откройте [новый тикет](https://github.com/sp404community/sp404community.github.io/issues) в репо `github.com/sp404community` и опишите суть инновации.
>
>И можно клонировать к себе этот репо, запустить у себя [Obsidian](https://obsidian.md/), внести правки и отправить pull request. Мы используем [Quartz](https://quartz.jzhao.xyz/) для публикации базы Obsidian в Github pages, к которым прикручен собственный домен `sp404.ru`. Документы, составляющие страницы, находятся в подпапке `/content`.
